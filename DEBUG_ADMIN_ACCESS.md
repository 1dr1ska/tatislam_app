# Debug Admin Access Instructions

## Как получить доступ к админке в debug-режиме

В debug-сборке приложения автоматически активируется функция debug-доступа к админке. Это позволяет разработчикам тестировать админ-панель без необходимости входа в систему с правами администратора.

### Как это работает

1. **Автоматическое включение**: В debug-сборке (flutter run --debug) доступ к админке включается автоматически
2. **Визуальный индикатор**: На главном экране появляется виджет "DEBUG ADMIN ACCESS" с оранжевой рамкой
3. **Прямой доступ**: Нажатие на иконку админки в виджете или переход по маршруту `/admin` разрешены

### Использование

1. Запустите приложение в debug-режиме:
   ```bash
   flutter run
   ```

2. Откройте главный экран приложения
3. В верхней части экрана вы увидите виджет "DEBUG ADMIN ACCESS"
4. Нажмите на иконку админки или используйте меню навигации для перехода в админ-панель

### Безопасность

- Эта функция работает **только** в debug-сборках
- В release-сборках (flutter build) debug-доступ автоматически отключается
- В production-версии приложения эта функция недоступна

### Технические детали

Функция реализована через:
- `debugAdminAccessProvider` - провайдер, проверяющий debug-режим
- `isAdminOrDebugProvider` - комбинированный провайдер для проверки доступа
- Модифицированный роутер с проверкой `kDebugMode`
- Виджет `DebugAdminAccess` на главном экране

### Устранение неполадок

Если debug-доступ не работает:
1. Убедитесь, что запускаете приложение в debug-режиме
2. Проверьте, что в консоли нет ошибок Dart
3. Убедитесь, что все зависимости установлены корректно
